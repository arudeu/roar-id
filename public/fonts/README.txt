Preview font: GT America

Put GT-America-Regular.ttf in this folder. app/globals.css loads it as /fonts/GT-America-Regular.ttf and
applies it to the previews (the .preview-font class). It is a licensed font, so it is not included here.

Only the Regular weight is declared, so bold text in the previews is the browser's synthesised bold.
To use real bold/italic files, add matching @font-face blocks (font-weight: 700, font-style: italic, ...)
for "GT America" in app/globals.css.
